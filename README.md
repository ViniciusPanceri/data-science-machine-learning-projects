# data-science-machine-learning-projects
# Machine Learning Applied to Business Problems

This project explores the application of Machine Learning techniques to solve two business-related problems: sales prediction and fraud detection.

The objective was to understand how data analysis and predictive models can support decision-making processes.

## Project Overview

This repository contains two Machine Learning applications developed using Python:

- Sales Prediction (Regression)
- Fraud Detection (Classification)

---

# 1. Sales Prediction

A regression model was created to predict sales based on historical data and promotional events.

## Methodology

The project included:

- Creating a dataset with sales history
- Data exploration and analysis
- Splitting data into training and testing sets
- Training a Linear Regression model
- Evaluating model performance

## Model Evaluation

Metrics used:

- Mean Squared Error (MSE)
- R² Score

The model achieved an R² score of approximately 0.80, showing a good relationship between input variables and predicted sales.

---

# 2. Fraud Detection

A classification model was developed to identify possible fraudulent transactions.

## Methodology

The project included:

- Creating transaction data
- Processing categorical variables
- Training a Logistic Regression model
- Evaluating predictions

## Model Evaluation

Metrics used:

- Accuracy
- Confusion Matrix
- Classification Report

The model evaluates the probability of transactions being classified as fraudulent or legitimate.
